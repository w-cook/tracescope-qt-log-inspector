Investigation of degraded behavior observed on field gateway GW-204 at NORTH-RIDGE-17. The session shows two elevated periods involving cellular signal loss, repeated reconnect attempts, Modbus timeouts, telemetry upload failures, queue growth, and delayed backlog processing. Findings focus on the progression from initial connectivity degradation through downstream buffering and worker-stall effects, with the known-good gateway session used as baseline context for comparison.
