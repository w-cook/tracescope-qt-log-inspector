TraceScope Documentation

TraceScope is a native C++/Qt desktop application for investigating file-based telemetry and diagnostic logs. For a project overview, features, screenshots, and release information, see the Project README.

User Guides

  • Getting Started — Set up TraceScope and complete a first investigation.
  • Importing Logs — Select log files, configure imports, and preview records.
  • Investigating Logs — Filter, navigate, and analyze imported events.
  • Findings — Bookmark records, record observations, and manage findings.
  • Live Following — Follow growing files and handle source changes.
  • Saving and Restoring — Preserve investigations and reopen workspaces.
  • Comparing Sessions — Compare investigation sessions using point-in-time results.
  • Reporting and Export — Export records and findings, and generate HTML reports.
